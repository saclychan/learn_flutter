# Bài 3: Code Generation (Tự sinh Code) với Freezed

Nếu bạn đã từng viết hàm `fromJson` và `toJson` bằng tay cho một class có 20 thuộc tính, và sau đó thêm 1 thuộc tính mới rồi quên cập nhật hàm... bạn sẽ hiểu thế nào là thảm họa. Là một Senior, bạn sẽ để máy móc viết code cho bạn.

> 💡 **Fun Fact:** Dart không có tính năng Reflection (Nội quan - Tự đọc cấu trúc class lúc runtime) mạnh mẽ như Java hay C# vì mục đích tối ưu hóa hiệu năng (AOT compilation). Do đó, giải pháp thay thế hoàn hảo là **Code Generation** (Sinh code lúc biên dịch bằng `build_runner`).

## 1. Vấn đề của Data Class thuần
Trong Dart, để có một class chứa dữ liệu hoàn chỉnh, bạn phải tự viết: Constructor, `copyWith`, `toString()`, và nạp chồng toán tử `==` (để so sánh giá trị thay vì so sánh ô nhớ).
Viết tay 1 class mất 10 phút. Viết 10 class mất 1 tiếng rưỡi chỉ để gõ phím lộc cộc.

## 2. Giải pháp: `freezed` & `json_serializable`
Thư viện `freezed` giúp bạn định nghĩa một class chỉ trong 3 dòng, sau đó nó tự động đẻ ra hàng ngàn dòng code khác phía sau hậu trường (vào một file ẩn có đuôi `.freezed.dart`).

```dart
// 1. Phải import annotation và part file
import 'package:freezed_annotation/freezed_annotation.dart';

part 'user.freezed.dart';
part 'user.g.dart';

// 2. Thêm @freezed
@freezed
class User with _$User {
  // 3. Khai báo thuộc tính cực ngắn gọn
  const factory User({
    required String id,
    required String name,
    int? age,
  }) = _User;

  // 4. Nếu cần JSON, thêm đúng 1 dòng này!
  factory User.fromJson(Map<String, dynamic> json) => _$UserFromJson(json);
}
```
Sau đó bạn mở Terminal, gõ lệnh:
```bash
dart run build_runner build -d
```
Bùm! Một ngàn dòng code an toàn, hoàn hảo, so sánh bằng `==` chuẩn xác và hàm `copyWith` tiện lợi được sinh ra ngay lập tức.

## 3. Pattern Matching (Union Types)
`freezed` còn mạnh ở chỗ tạo ra Union Type (Nhiều trạng thái trong 1 class), cực kỳ hữu dụng khi làm State Management (BLoC).
```dart
@freezed
class Result with _$Result {
  const factory Result.loading() = _Loading;
  const factory Result.success(String data) = _Success;
  const factory Result.error(String message) = _Error;
}

// Khi dùng, bắt buộc phải cover đủ 3 trường hợp, quên 1 cái báo lỗi đỏ lòm. An toàn tuyệt đối!
result.when(
  loading: () => print('Đang tải...'),
  success: (data) => print('Có data: $data'),
  error: (msg) => print('Lỗi: $msg'),
);
```

## 🛑 Những nỗi đau và ngộ nhận khi còn Junior
- **Sợ file lỗi màu đỏ:** Khi vừa gõ xong file freezed (chưa chạy `build_runner`), IDE sẽ báo lỗi đỏ lòe loẹt ở chữ `_$User`. Junior hoảng sợ xóa sạch code. **Cách phòng tránh:** Hiểu rằng file part chưa được sinh ra nên đỏ là hiển nhiên. Hãy bình tĩnh chạy lệnh `build_runner` rồi mọi lỗi đỏ sẽ biến mất!
- **Sửa code trong file sinh tự động:** Mở file `.g.dart` hoặc `.freezed.dart` ra và gõ code vào đó. Lần chạy `build_runner` tiếp theo, mọi code viết tay ở đó sẽ bị xóa sạch bóng. **Cách phòng tránh:** KHÔNG BAO GIỜ đụng vào file được sinh tự động.

### 🚀 Mini Pet Project: Cỗ Máy Đẻ Code (Generator Machine)

**Yêu cầu:**
1. Khởi tạo một project Flutter/Dart. Thêm các package: `freezed_annotation`, `json_annotation` vào `dependencies`. Thêm `build_runner`, `freezed`, `json_serializable` vào `dev_dependencies`.
2. Tạo file `product.dart`. Định nghĩa class `Product` bằng cú pháp của freezed, có 3 thuộc tính: `id` (String), `price` (double), `isAvailable` (bool, mặc định true).
3. Đừng quên dòng `part 'product.freezed.dart';`.
4. Mở terminal, chạy lệnh `dart run build_runner build`.
5. Tạo 2 object Product có nội dung giống hệt nhau. Dùng toán tử `==` so sánh chúng. In ra xem nó báo `true` hay `false`. (Nếu là class thường sẽ là false, nhưng freezed sẽ trả về true!).

> 🔗 **Tài liệu tham khảo (Ref Docs):**
> - [Freezed Package](https://pub.dev/packages/freezed)
> - [JSON and serialization](https://docs.flutter.dev/data-and-backend/serialization/json)
