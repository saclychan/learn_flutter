# Bài 7: Animations Masterclass

Để app có hồn, không thể thiếu hiệu ứng chuyển động (Animation). Ở bài này, ta sẽ đi từ những hiệu ứng "ăn liền" đến việc tự tuỳ chỉnh từng khung hình.

---

## 1. Mức độ Newbie: Implicit Animations (Hoạt hình Ngầm định)

Cách dễ nhất để làm Animation là dùng các Widget có chữ `Animated` ở đầu (vd: `AnimatedContainer`, `AnimatedOpacity`, `AnimatedPadding`). Em chỉ cần đổi biến số và gọi `setState`, Flutter sẽ tự lo phần chuyển động.

### Code minh họa cơ bản
```dart
class MyAnimation extends StatefulWidget {
  @override
  _MyAnimationState createState() => _MyAnimationState();
}

class _MyAnimationState extends State<MyAnimation> {
  bool _isBig = false;

  @override
  Widget build(BuildContext context) {
    return GestureDetector(
      onTap: () => setState(() => _isBig = !_isBig),
      child: AnimatedContainer(
        duration: const Duration(seconds: 1),
        curve: Curves.easeInOut,
        width: _isBig ? 200 : 100,
        height: _isBig ? 200 : 100,
        color: _isBig ? Colors.blue : Colors.red,
      ),
    );
  }
}
```

## 2. Mức độ Senior: Explicit Animations (Hoạt hình Tường minh)

Khi em muốn kiểm soát vòng đời của hiệu ứng (Chạy, Dừng, Lặp lại, Đảo ngược), em phải dùng `AnimationController`.

### 2.1. Cấu trúc của Explicit Animation
- **Ticker:** Đồng hồ đếm nhịp (thường gọi 60 lần/giây). Dùng `SingleTickerProviderStateMixin`.
- **AnimationController:** Trái tim của hiệu ứng. Quản lý giá trị từ 0.0 đến 1.0.
- **Tween:** Ánh xạ từ [0.0 - 1.0] sang [A - B] (vd: từ màu Đỏ sang Xanh, từ 0px sang 100px).
- **AnimatedBuilder:** Widget lắng nghe Controller để vẽ lại giao diện mà không cần gọi `setState` làm rebuild cả trang.

### 2.2. Tối ưu hiệu suất vẽ
Không bao giờ dùng `setState` để chạy animation vì nó làm dirty toàn bộ State và Widget Tree. Thay vào đó, bọc phần cần chạy bằng `AnimatedBuilder` hoặc sử dụng các widget như `RotationTransition`, `FadeTransition`... 

---

## 3. Lời khuyên Google Style Guide
- **Dispose Controller:** BẮT BUỘC phải gọi `_controller.dispose()` khi thoát khỏi màn hình, nếu không `Ticker` vẫn sẽ tiếp tục đếm nhịp ở background làm cháy CPU và hao pin người dùng.

## 4. Nỗi đau Junior (Junior Pitfalls)

❌ **Sai lầm: Dùng setState chạy Animation bằng tay**
```dart
// Junior tạo Timer.periodic và setState tăng dần biến width
// Gây lag, rớt khung hình (drop FPS).
```

✅ **Đúng: Dùng TweenAnimationBuilder nếu lười tạo Controller**
Nếu em cần hiệu ứng phức tạp hơn Implicit nhưng chưa muốn dùng Controller nặng nề, hãy dùng `TweenAnimationBuilder`.
```dart
TweenAnimationBuilder<double>(
  tween: Tween<double>(begin: 0, end: 100),
  duration: const Duration(seconds: 1),
  builder: (context, value, child) {
    return Container(width: value, height: value, color: Colors.blue);
  },
);
```

## 5. 🐛 Thử Thách Gỡ Lỗi (Intentional Bugs)

Dưới đây là một vòng xoay. Khi chạy thì không thấy lỗi, nhưng khi pop (back) lại trang trước, Console đỏ chót báo "Ticker failed to dispose...".

```dart
class BuggySpinner extends StatefulWidget {
  @override
  _BuggySpinnerState createState() => _BuggySpinnerState();
}

class _BuggySpinnerState extends State<BuggySpinner> with SingleTickerProviderStateMixin {
  late AnimationController _controller;

  @override
  void initState() {
    super.initState();
    _controller = AnimationController(vsync: this, duration: const Duration(seconds: 2))..repeat();
  }

  @override
  Widget build(BuildContext context) {
    return RotationTransition(
      turns: _controller,
      child: const Icon(Icons.sync, size: 50),
    );
  }
  
  // 🐛 Em có quên làm gì khi class này bị huỷ không?
}
```
> **Gợi ý:** Rác tạo ra thì phải dọn dẹp. Hãy nhớ lại hàm nào được gọi khi Widget bị xóa khỏi cây?

## 6. 🚀 Mini Pet Project

**Yêu cầu:** 
Tạo một nút "Thả Tim" (Like Button):
1. Dùng `GestureDetector` bọc ngoài Icon(Icons.favorite).
2. Khi người dùng bấm vào, màu của trái tim đổi từ Xám sang Đỏ (dùng `AnimatedContainer` hoặc `TweenAnimationBuilder` màu sắc).
3. *Thử thách khó:* Cùng lúc đó, kích thước trái tim phóng to lên gấp 1.5 lần rồi thu lại bình thường (như tiếng nhịp tim). Gợi ý: Tìm hiểu về tham số `curve` hoặc dùng `AnimationController` kết hợp `SequenceAnimation`.
