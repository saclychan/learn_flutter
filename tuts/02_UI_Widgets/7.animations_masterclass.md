# Bài 7: Animations (Hoạt ảnh) - Thổi hồn vào ứng dụng

Sự khác biệt lớn nhất giữa một cái "App phèn" và một cái "App xịn" chính là ở những hiệu ứng chuyển động mượt mà (micro-interactions). Nhờ sức mạnh của Skia/Impeller engine, Flutter vẽ Animation cực kỳ bá đạo ở mức 60-120fps.

> 💡 **Fun Fact:** Flutter phân chia Animation làm 2 loại chính: Implicit (Ngầm định - Dễ dùng, cấu hình ít, Flutter tự tính toán đường đi) và Explicit (Tường minh - Khó dùng, cấu hình nhiều, nhưng kiểm soát được mọi Frame).

## 1. Implicit Animations (Phép thuật tự động)
Bạn có một cái Hộp màu Xanh, 1 giây sau bạn đổi màu nền thành Đỏ bằng `setState`. Giao diện sẽ đổi màu "Bụp" một cái ngay lập tức. Cứng nhắc!

Nhưng nếu bạn dùng `AnimatedContainer` thay vì `Container`, nó sẽ tự động tính toán dải màu từ Xanh chuyển dần sang Đỏ trong vòng 1 khoảng thời gian bạn cho trước. Mượt mà như lụa!

```dart
AnimatedContainer(
  duration: const Duration(milliseconds: 500),
  curve: Curves.easeInOut, // Đường cong gia tốc chuyển động
  width: isExpanded ? 200 : 100, // Chỉ cần setState đổi biến isExpanded, width sẽ tự phình ra dần dần!
  color: isExpanded ? Colors.red : Colors.blue,
  child: const Text('Phép màu'),
)
```
Tương tự: `AnimatedOpacity`, `AnimatedPadding`, `AnimatedAlign`...

## 2. Explicit Animations (AnimationController)
Khi bạn muốn một cái hộp xoay tròn liên tục không bao giờ ngừng, hoặc một bánh răng quay thuận rồi quay ngược theo % tiến trình, Implicit "đầu hàng". Bạn cần `AnimationController`.

```dart
// Màn hình bắt buộc gắn mixin SingleTickerProviderStateMixin
late AnimationController _controller;

@override
void initState() {
  super.initState();
  _controller = AnimationController(
    vsync: this, // Đồng bộ khung hình với tần số quét của máy
    duration: const Duration(seconds: 2),
  )..repeat(); // Quay vòng lặp bất tận
}

// Bên dưới UI, đưa _controller vào một AnimatedBuilder
AnimatedBuilder(
  animation: _controller,
  builder: (context, child) {
    return Transform.rotate(
      angle: _controller.value * 2 * math.pi, // Xoay 360 độ
      child: const Icon(Icons.settings),
    );
  },
)
```

> 🧠 **Senior Detail:** Vsync (Vertical Synchronization) đóng vai trò ngăn không cho Flutter vẽ khung hình (render frame) khi màn hình thiết bị đang bị tắt hoặc app rơi vào background. Nó giúp tiết kiệm hàng đống pin! Hãy LUÔN LUÔN `.dispose()` cái `_controller` khi hủy widget nhé.

## 3. Chuyển màn hình với "Người Hùng" (Hero Animation)
Từ màn hình danh sách, bạn bấm vào một cái ảnh bé xíu, màn hình mới hiện ra và cái ảnh bé xíu đó "bay lượn" phình to ra đúng chỗ của nó. Đó là Hero Animation.

Bạn chỉ việc bọc bức ảnh bên màn 1 bằng `Hero(tag: 'id_123', child: Image)`, và bọc bức ảnh bên màn 2 cũng bằng đúng cái thẻ `Hero(tag: 'id_123', child: Image)`. Flutter lo phần còn lại. Khủng khiếp chưa!

## 🛑 Những nỗi đau và ngộ nhận khi còn Junior
- **Bạ đâu cũng dùng AnimationController:** Thích thể hiện kỹ năng, Junior lôi `AnimationController` ra code một hiệu ứng Fade In kéo dài 80 dòng code. **Cách phòng tránh:** Hãy xài `AnimatedOpacity` chỉ tốn đúng 3 dòng! Luôn ưu tiên dùng hàng Implicit có sẵn trước khi lôi "vũ khí hạng nặng" Explicit ra xài.
- **Để Animation chạy khi widget đã chết:** Widget bị văng đi mà AnimationController vẫn cặm cụi tính toán trong bóng đêm gây memory leak.

### 🚀 Mini Pet Project: Nút Bấm "Tim Đập" (Heartbeat Button)

**Yêu cầu:**
1. Tạo một UI có cái Icon hình trái tim (`Icons.favorite`) màu đỏ bọc trong một cái nút.
2. Viết một `AnimationController` có chu kỳ 1 giây, thực hiện thu phóng (Scale) trái tim từ kích thước 1.0 lên 1.3 rồi về lại 1.0. (Gợi ý dùng `TweenSequence` hoặc `repeat(reverse: true)`).
3. Bọc cái Icon trong `AnimatedBuilder` và dùng `Transform.scale` để biến đổi độ lớn theo controller.
4. Bấm nút F5 và thưởng thức một trái tim đập thình thịch cực sinh động giữa màn hình!
