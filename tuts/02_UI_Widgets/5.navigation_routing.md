# Bài 5: Điều hướng (Navigation) và Routing

Trong Flutter, một "Màn hình" thực chất chỉ là một Widget được bao phủ toàn bộ thiết bị. Việc chuyển qua lại giữa các màn hình được gọi là Navigation (Điều hướng).

> 💡 **Fun Fact:** Hệ thống Navigation cơ bản của Flutter 1.0 (Navigator 1.0) dùng cấu trúc Stack (ngăn xếp), giống như một tập hồ sơ. Bạn "Push" (đẩy) một tờ giấy mới lên trên cùng để xem màn hình mới, và "Pop" (rút) tờ giấy trên cùng đi để quay về màn hình cũ.

## 1. Cách dùng Navigator 1.0 cơ bản
Đẩy (Push) một màn hình mới lên trên:
```dart
Navigator.of(context).push(
  MaterialPageRoute(
    builder: (context) => const DetailsScreen(),
  ),
);
```

Quay về (Pop):
```dart
Navigator.of(context).pop(); // Hoặc đơn giản là user bấm nút Back trên điện thoại
```

> 🧠 **Senior Detail:** Nếu bạn làm App tin tức, user nhấn Đọc tin A -> B -> C -> D. Đỉnh Stack lúc này có 4 màn hình. Khi user bấm nút "Về trang chủ", đừng dùng `push` màn hình Home mới lên thành 5. Hãy dùng `Navigator.of(context).popUntil((route) => route.isFirst);` để giũ bỏ 4 lớp rác, trả hệ thống về màn hình gốc.

## 2. Ngăn chặn User bấm nút Back bừa bãi (PopScope)
Khi user đang ở màn hình điền Form phức tạp chưa kịp lưu mà nhỡ tay vuốt Back, làm sao chặn họ lại để hiện cảnh báo "Bạn có chắc muốn thoát?"

Thay vì `WillPopScope` (đã bị bỏ), giờ ta dùng `PopScope`:
```dart
PopScope(
  canPop: false, // Ngăn chặn pop tự động
  onPopInvoked: (didPop) {
    if (didPop) return; // Nếu đã bị pop, thoát
    // Nếu chưa pop (do canPop = false), hiện Dialog hỏi user:
    showDialog(...);
  },
  child: Scaffold(...),
)
```

## 3. Truyền dữ liệu giữa các màn hình
Bạn muốn đẩy data sang màn hình con? Hãy cho constructor của màn hình con nhận biến.
Bạn muốn màn hình con trả data về cho màn hình cha? Dùng giá trị return của `pop()`.
```dart
// Màn hình Cha gọi màn con và chờ kết quả
final result = await Navigator.of(context).push(
  MaterialPageRoute(builder: (context) => SelectionScreen()),
);
print("Cha nhận được: $result");

// Màn hình Con chọn data và trả về
Navigator.of(context).pop('Yes!'); // Trả chuỗi "Yes!" về cho cha
```

## 🛑 Những nỗi đau và ngộ nhận khi còn Junior
- **Mì Spaghetti Navigator 1.0:** Junior dùng lệnh push khắp mọi nơi. Khi app to ra, yêu cầu xử lý Deep Link (bấm link mở thẳng vào màn Details trong app), dùng Navigator 1.0 là một cực hình. **Cách phòng tránh:** Hiểu Navigator 1.0 cho biết, còn đi làm thực tế, hãy cài đặt và sử dụng gói `go_router` (Navigation 2.0 do chính Google chống lưng). Nó xịn xò và quản lý Route theo định dạng URL (vd: `/home/details/123`).
- **Giao diện Bottom Navigation Bar sai bét:** Thay vì dùng 1 khung (Shell) giữ cố định thanh Bar và thay ruột ở giữa, Junior lại nhét thanh Navigation vào CẢ 3 màn hình và Push qua Push lại giữa chúng. **Cách phòng tránh:** Tìm hiểu `StatefulShellRoute` trong thư viện GoRouter!
