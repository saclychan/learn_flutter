# Bài 4: Forms và Validation - Thu thập dữ liệu người dùng

Giao diện đẹp mà không lấy được dữ liệu của người dùng thì vô nghĩa. Trong Flutter, `Form` và `TextFormField` là bộ đôi quyền lực để tạo ra các màn hình Đăng ký/Đăng nhập chuyên nghiệp.

> 💡 **Fun Fact:** Bạn có biết tại sao lại có cả `TextField` và `TextFormField` không? `TextFormField` thực chất là một `TextField` được bọc bên trong một lớp FormField, giúp nó có sẵn các hàm `validator` và `onSaved` liên kết trực tiếp với cái `Form` bao ngoài!

## 1. Cơ bản về TextFormField
Khác với `TextField` thuần, `TextFormField` sinh ra để hoạt động trong một cái `Form`.

```dart
TextFormField(
  decoration: const InputDecoration(
    labelText: 'Email',
    border: OutlineInputBorder(),
    prefixIcon: Icon(Icons.email),
  ),
  keyboardType: TextInputType.emailAddress, // Bàn phím có phím @
  validator: (value) {
    if (value == null || value.isEmpty) {
      return 'Vui lòng nhập Email'; // Chuỗi trả về sẽ làm màu đỏ ô input
    }
    if (!value.contains('@')) {
      return 'Email không hợp lệ';
    }
    return null; // Trả về null nghĩa là dữ liệu HỢP LỆ!
  },
)
```

## 2. GlobalKey - "Chìa khóa" quản lý toàn bộ Form
Để kiểm tra xem tất cả các ô trong form đã hợp lệ chưa (Validate All), bạn cần một `GlobalKey<FormState>`.

```dart
final _formKey = GlobalKey<FormState>();

// Bao bọc các TextFormField bằng Form
Form(
  key: _formKey,
  child: Column(
    children: [
      TextFormField(...),
      TextFormField(...),
      ElevatedButton(
        onPressed: () {
          // Khi bấm nút, nó sẽ duyệt qua toàn bộ validator của các TextFormField
          if (_formKey.currentState!.validate()) {
            ScaffoldMessenger.of(context).showSnackBar(
              const SnackBar(content: Text('Xử lý dữ liệu...')),
            );
          }
        },
        child: const Text('Đăng ký'),
      ),
    ],
  ),
)
```

## 3. TextEditingController
Nếu bạn muốn chủ động lấy dữ liệu, xóa chữ trong ô, hoặc thay đổi text mà không cần thông qua biến state, hãy dùng `TextEditingController`.

> 🧠 **Senior Detail:** Controller là một bộ nhớ độc lập chạy song song với giao diện. Rất nhiều Junior khai báo `TextEditingController` nhưng QUÊN KHÔNG `dispose()` nó trong vòng đời `dispose` của StatefulWidget. Hậu quả: App bị rò rỉ bộ nhớ (Memory Leak) âm ỉ, dùng lâu sẽ giật tung chảo! Luôn luôn nhớ `.dispose()` controller!

## 🛑 Những nỗi đau và ngộ nhận khi còn Junior
- **Nhét bừa TextField vào Column không bọc ScrollView:** Khi bạn bấm vào ô chữ, bàn phím mềm hiện lên che khuất màn hình, ngay lập tức bạn ăn cái sọc vàng đen "Bottom overflowed by xxx pixels". **Cách phòng tránh:** LUÔN LUÔN bọc giao diện nhập liệu bên trong một `SingleChildScrollView`.
- **Dùng State cho từng phím bấm:** Gắn `setState` vào thuộc tính `onChanged` của ô password để theo dõi độ dài. Sai lầm! Nó làm toàn bộ màn hình bị giật mỗi khi bạn gõ một chữ. **Cách phòng tránh:** Dùng `TextEditingController` hoặc `Form.onSaved`.

### 🚀 Mini Pet Project: Màn hình Đăng ký Tài khoản (Sign-up Form)

**Yêu cầu:**
1. Tạo một StatefulWidget tên `SignUpScreen`.
2. Tạo form với 3 trường: Họ Tên (không được trống), Email (phải có @), và Password (ít nhất 6 ký tự).
3. Sử dụng `obscureText: true` cho ô Password. Thêm một cái icon con mắt, dùng `setState` bật tắt con mắt để hiện/ẩn mật khẩu.
4. Một nút "Tạo tài khoản". Khi bấm, nếu Form `validate()` trả về true, in ra Terminal "Tạo tài khoản thành công!". Nếu false, các ô nhập liệu sẽ tự hiện chữ đỏ cảnh báo.
