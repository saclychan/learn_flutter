# Bài 6: Giao diện Tương thích (Responsive & Adaptive UI)

App của bạn chạy ngon trên chiếc iPhone 14 Pro, nhưng khi đưa lên cái iPad 12.9 inch thì mọi thứ bị vỡ nát hoặc chữ cái bé xíu xiu. Đây là lúc bạn cần học về Responsive UI.

> 💡 **Fun Fact:** Flutter không chỉ làm app Mobile, nó build cho cả Web, Windows, macOS, Linux. Thế nên việc làm giao diện tự động thích ứng với kích thước màn hình là điều BẮT BUỘC.

## 1. Vùng an toàn (SafeArea)
Các điện thoại đời mới đều có "Tai thỏ" (Notch), "Đảo động" (Dynamic Island), hoặc thanh Home ảo ở đáy.
Nếu bạn không bọc toàn bộ nội dung của mình bằng `SafeArea`, chữ của bạn sẽ chui còng cọc vào tai thỏ, làm user không đọc được.

```dart
@override
Widget build(BuildContext context) {
  return Scaffold(
    body: SafeArea(
      child: Text('Chữ này sẽ không bao giờ đè lên tai thỏ!'),
    ),
  );
}
```

## 2. Lấy kích thước thiết bị (MediaQuery)
Để tính toán chiều cao hoặc độ rộng chính xác của màn hình, dùng `MediaQuery`.
```dart
final screenWidth = MediaQuery.of(context).size.width;
final isLandscape = MediaQuery.of(context).orientation == Orientation.landscape;
```

> 🧠 **Senior Detail:** Việc lạm dụng `MediaQuery.of(context).size` có một cái giá rất đắt! Khi bàn phím hiện lên, Size bị thay đổi, dẫn đến TOÀN BỘ widget nào dùng câu lệnh đó sẽ bị Rebuild vô ích. **Tuyệt chiêu:** Thay vì đo nguyên cái màn hình, hãy dùng `LayoutBuilder` để đo kích thước của khung chứa widget cục bộ.

## 3. LayoutBuilder
Đây là Widget quyền lực nhất để làm giao diện Responsive. Thay vì phụ thuộc vào màn hình, `LayoutBuilder` cung cấp cho bạn biết kích thước không gian trống tối đa mà widget "Cha" chừa lại cho widget "Con".

```dart
LayoutBuilder(
  builder: (context, constraints) {
    if (constraints.maxWidth > 600) {
      // Màn hình rộng (Tablet, Web) -> Hiển thị chia 2 cột
      return Row(children: [MenuSide(), ContentMain()]);
    } else {
      // Màn hình hẹp (Mobile) -> Hiển thị 1 cột
      return ContentMain();
    }
  },
)
```

## 🛑 Những nỗi đau và ngộ nhận khi còn Junior
- **Hardcode chiều cao tuyệt đối:** Junior hay gõ `Container(height: 800)`. Lên máy dài thì thiếu hụt, lên máy ngắn thì tràn viền sọc vàng đen. **Cách phòng tránh:** Dùng `Flexible`, `Expanded`, hoặc dùng tỷ lệ phần trăm (như `MediaQuery.size.height * 0.3`).
- **Khóa xoay màn hình vĩnh viễn:** Vì sợ xoay ngang làm vỡ UI, nhiều dev lén lút cấu hình khóa cứng app ở chế độ xoay dọc (Portrait Only) và hy vọng không ai phát hiện. Đó không phải là fix bug, đó là giấu dốt.

### 🚀 Mini Pet Project: Bảng điều khiển Đa thiết bị (Responsive Dashboard)

**Yêu cầu:**
1. Tạo một UI có `LayoutBuilder` bọc ở thân `Scaffold`.
2. Tạo 1 widget giả lập danh sách bạn bè (Bạn vẽ `ListView` đơn giản gồm các tên).
3. Logic như sau: 
   - Nếu `maxWidth < 500` (Điện thoại dọc): Chỉ hiện thị danh sách bạn bè.
   - Nếu `maxWidth >= 500` (Xoay ngang điện thoại hoặc iPad): Hiển thị `Row` chia đôi màn hình. Nửa bên trái là danh sách bạn bè, nửa bên phải hiển thị câu `Text('Chọn một người bạn để chat')`.
4. Dùng tính năng Rotate Screen của Simulator hoặc thu phóng cửa sổ trình duyệt (nếu chạy Web) để xem sự "ảo thuật".
