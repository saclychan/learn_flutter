# Flutter 101.3 — bố cục với Row, Column và Container

Ở bài trước, bạn đã tạo bộ đếm. Bài này dạy cách **đặt các widget đúng vị trí** để biến những mảnh rời rạc thành một giao diện dễ nhìn.

Mục tiêu: làm một trang hồ sơ nhỏ có avatar, tên, mô tả và hai nút hành động.

## 1. Bố cục trong Flutter là widget lồng nhau

Flutter không dùng XML layout như Android truyền thống. Bạn mô tả bố cục bằng widget Dart:

```text
Scaffold
└── Padding                 tạo lề quanh màn hình
    └── Column              xếp nội dung từ trên xuống
        ├── CircleAvatar    ảnh đại diện tròn
        ├── Text            tên
        ├── Text            mô tả
        └── Row             xếp hai nút theo hàng ngang
            ├── OutlinedButton
            └── ElevatedButton
```

Đọc cây này từ trên xuống: widget cha chứa widget con. Giao diện nhìn như thế nào phụ thuộc rất nhiều vào widget bố cục cha.

## 2. Ba widget bố cục quan trọng

| Widget | Nó là gì? | Dùng khi nào? |
| --- | --- | --- |
| `Column` | Xếp nhiều widget theo chiều dọc. | Tiêu đề trên, nội dung dưới; danh sách form; trang hồ sơ. |
| `Row` | Xếp nhiều widget theo chiều ngang. | Icon cạnh chữ; hai nút nằm cạnh nhau. |
| `Container` | Hộp có thể có kích thước, màu nền, viền, bo góc. | Tạo thẻ (card), vùng màu hoặc khung trang trí. |
| `Padding` | Thêm khoảng trống **bên trong** quanh widget con. | Không để nội dung dính sát mép. |
| `SizedBox` | Hộp trống/có kích thước cố định. | Tạo khoảng cách đơn giản giữa hai widget. |
| `Expanded` | Bảo widget con chiếm phần không gian còn lại trong `Row`/`Column`. | Làm nút rộng đều, hoặc để text dùng hết chiều ngang còn lại. |

> `margin` là khoảng trống **bên ngoài** một `Container`; `padding` là khoảng trống **bên trong**, giữa viền và nội dung. Khi mới học, dùng `Padding` và `SizedBox` là đủ cho đa số màn hình.

## 3. Thực hành: trang hồ sơ

Mở `hello_flutter/lib/main.dart` và thay toàn bộ bằng code sau:

```dart
import 'package:flutter/material.dart';

void main() {
  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      debugShowCheckedModeBanner: false,
      theme: ThemeData(colorSchemeSeed: Colors.indigo),
      home: const ProfilePage(),
    );
  }
}

class ProfilePage extends StatelessWidget {
  const ProfilePage({super.key});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Hồ sơ')),
      body: Padding(
        padding: const EdgeInsets.all(24),
        child: Column(
          crossAxisAlignment: CrossAxisAlignment.center,
          children: [
            const SizedBox(height: 24),
            const CircleAvatar(
              radius: 56,
              child: Icon(Icons.person, size: 64),
            ),
            const SizedBox(height: 16),
            const Text(
              'Người học Flutter',
              style: TextStyle(fontSize: 24, fontWeight: FontWeight.bold),
            ),
            const SizedBox(height: 8),
            const Text(
              'Đang xây ứng dụng đầu tiên của mình.',
              textAlign: TextAlign.center,
            ),
            const SizedBox(height: 24),
            Container(
              width: double.infinity,
              padding: const EdgeInsets.all(16),
              decoration: BoxDecoration(
                color: Colors.indigo.shade50,
                borderRadius: BorderRadius.circular(12),
              ),
              child: const Text('Mục tiêu hôm nay: hiểu bố cục Flutter.'),
            ),
            const Spacer(),
            Row(
              children: [
                Expanded(
                  child: OutlinedButton(
                    onPressed: () {},
                    child: const Text('Để sau'),
                  ),
                ),
                const SizedBox(width: 12),
                Expanded(
                  child: ElevatedButton(
                    onPressed: () {},
                    child: const Text('Bắt đầu'),
                  ),
                ),
              ],
            ),
          ],
        ),
      ),
    );
  }
}
```

Lưu file. Bạn sẽ thấy giao diện thay đổi ngay bằng hot reload. Hai nút chưa làm gì — `onPressed: () {}` là một hàm rỗng tạm thời; sang bài sau ta sẽ cho nút thực hiện hành động.

## 4. Giải thích code mới

| Code | Nó là gì? | Tác dụng |
| --- | --- | --- |
| `ThemeData(colorSchemeSeed: Colors.indigo)` | Cấu hình theme chung cho app. | Flutter tự tạo các màu đồng bộ từ màu hạt giống `indigo`. |
| `EdgeInsets.all(24)` | Giá trị khoảng cách 24 ở bốn phía. | Làm nội dung không dính mép màn hình. |
| `crossAxisAlignment` | Cách căn chỉnh theo trục phụ của `Column`. | Với `Column`, trục chính là dọc, nên trục phụ là ngang. `center` căn nội dung giữa ngang. |
| `CircleAvatar` | Widget hình tròn thường dùng làm avatar. | Hiển thị icon người trong một vòng tròn. |
| `Icons.person` | Biểu tượng có sẵn trong Material Icons. | Không cần tải file ảnh để thử giao diện. |
| `textAlign: TextAlign.center` | Cách căn chữ trong vùng của `Text`. | Căn giữa đoạn mô tả nếu nó dài hơn một dòng. |
| `width: double.infinity` | Chiều rộng lớn nhất cha cho phép. | Làm thẻ thông báo rộng hết vùng nội dung. |
| `BoxDecoration` | Cấu hình hình dáng/trang trí của `Container`. | Đặt màu nền và bo góc cho thẻ. |
| `Spacer()` | Widget chiếm toàn bộ khoảng trống còn lại trong `Column`. | Đẩy hàng nút xuống gần đáy màn hình. |
| `Expanded` | Widget co giãn trong `Row`/`Column`. | Mỗi nút lấy một nửa chiều rộng còn lại, nên hai nút bằng nhau. |

## 5. Trục chính và trục phụ

Đây là ý tưởng quan trọng nhất của bài.

| Widget | Trục chính (main axis) | Trục phụ (cross axis) |
| --- | --- | --- |
| `Column` | Dọc, từ trên xuống | Ngang, trái sang phải |
| `Row` | Ngang, trái sang phải | Dọc, trên xuống |

Ví dụ, thử đổi `crossAxisAlignment` của `Column`:

```dart
crossAxisAlignment: CrossAxisAlignment.start,
```

Các widget sẽ dồn sang trái. Đổi lại `center` sau khi quan sát.

Nếu muốn giãn đều các phần tử trong một `Row`, dùng:

```dart
mainAxisAlignment: MainAxisAlignment.spaceBetween,
```

Nhưng với hai nút cần rộng bằng nhau, `Expanded` phù hợp hơn.

## 6. Lỗi phổ biến: tràn màn hình

Nếu bạn thấy sọc vàng-đen và thông báo **overflowed**, nghĩa là nội dung lớn hơn diện tích được phép. Đừng cố “chữa” bằng cách giảm cỡ chữ ngay; trước hết xem widget cha có cần cuộn không.

Với trang dài, thay `Column` ngoài cùng bằng `SingleChildScrollView` bọc `Column`:

```dart
body: SingleChildScrollView(
  child: Padding(
    padding: const EdgeInsets.all(24),
    child: Column(
      children: [
        // các widget của bạn
      ],
    ),
  ),
),
```

Lưu ý: không dùng `Spacer` hoặc `Expanded` trong `Column` nằm trong `SingleChildScrollView`, vì chiều cao khi đó là không giới hạn. Hãy thay `Spacer()` bằng `SizedBox(height: 48)` trong trường hợp này.

## 7. Bài tập nhỏ

1. Đổi tên và mô tả thành thông tin của bạn.
2. Đổi `Colors.indigo` sang `Colors.teal` hoặc một màu khác.
3. Đổi `radius: 56` thành `80` và quan sát avatar.
4. Thêm một dòng `Text('Flutter beginner')` dưới tên, nhớ thêm `SizedBox` để tạo khoảng cách.
5. Thử bỏ một `Expanded` quanh nút. Vì sao hai nút không còn rộng bằng nhau?
6. Xoay iPhone Simulator hoặc thu hẹp cửa sổ Chrome để kiểm tra UI có còn ổn không.

## Ghi nhớ

- `Column`: xếp dọc; `Row`: xếp ngang.
- `Padding` tạo lề trong; `SizedBox` tạo khoảng cách; `Container` tạo hộp có trang trí.
- Dùng `Expanded` khi một widget cần chia không gian với widget cùng hàng/cột.
- Khi nội dung có thể dài hơn màn hình, nghĩ đến `SingleChildScrollView`.
