# Bài 1: Firebase Đăng nhập và Database Thời gian thực

Để làm Backend cho app (nơi chứa Database và code Server), bạn có thể dùng Nodejs, Java, Python. Nhưng nếu bạn làm Flutter, Firebase (cũng của Google) là người bạn thân nhất. Nó là Backend-as-a-Service (BaaS), làm sẵn mọi thứ cho bạn.

> 💡 **Fun Fact:** Ngày xưa muốn dùng Firebase với Flutter bạn phải cài đặt Gradle/Cocoapods lằng nhằng rớt nước mắt. Giờ đây, chỉ cần cài công cụ `flutterfire_cli`, gõ ĐÚNG 1 lệnh `flutterfire configure`, nó sẽ tự móc nối toàn bộ config của iOS/Android cho bạn trong 3 giây!

## 1. Firebase Authentication (Đăng nhập)
Không cần viết hàm băm mật khẩu, không cần làm hệ thống cấp token, không cần thiết lập quên mật khẩu gửi OTP. Firebase lo hết.

```dart
// Đăng ký cực dễ
try {
  final userCredential = await FirebaseAuth.instance.createUserWithEmailAndPassword(
    email: "barry.allen@example.com",
    password: "SuperSecretPassword!"
  );
  print("Chào mừng User ID: \${userCredential.user?.uid}");
} on FirebaseAuthException catch (e) {
  if (e.code == 'weak-password') {
    print('Password quá yếu.');
  } else if (e.code == 'email-already-in-use') {
    print('Email đã được dùng.');
  }
}
```
Lắng nghe trạng thái đăng nhập:
```dart
StreamBuilder<User?>(
  stream: FirebaseAuth.instance.authStateChanges(),
  builder: (context, snapshot) {
    if (snapshot.hasData) return HomeScreen(); // Đã login
    return LoginScreen(); // Chưa login
  },
)
```

## 2. Cloud Firestore (Database siêu tốc độ)
Khác với SQLite là CSDL quan hệ (Bảng và Cột), Firestore là NoSQL (Document và Collection). Nó lưu dữ liệu dạng JSON.

Ghi dữ liệu:
```dart
await FirebaseFirestore.instance.collection('users').doc('user_123').set({
  'name': 'Darth Vader',
  'age': 45,
  'isSith': true
});
```

> 🧠 **Senior Detail:** Điểm "ăn tiền" khủng khiếp nhất của Firestore là chức năng `snapshots()`. Nó trả về một `Stream`. Tức là nếu có ai đó đổi data trên Server, App của bạn sẽ TỰ ĐỘNG nhận được data mới và rebuild UI ngay lập tức mà không cần gọi hàm lấy lại data (Real-time).

```dart
StreamBuilder<QuerySnapshot>(
  stream: FirebaseFirestore.instance.collection('chat_room').snapshots(),
  builder: (context, snapshot) {
    if (snapshot.hasError) return Text('Lỗi cmnr');
    if (snapshot.connectionState == ConnectionState.waiting) return CircularProgressIndicator();
    
    // Data đổ về đây dưới dạng List các JSON (Documents)
    return ListView(
      children: snapshot.data!.docs.map((DocumentSnapshot document) {
        Map<String, dynamic> data = document.data()! as Map<String, dynamic>;
        return ListTile(
          title: Text(data['message']),
          subtitle: Text(data['sender']),
        );
      }).toList(),
    );
  },
)
```

## 🛑 Những nỗi đau và ngộ nhận khi còn Junior
- **Đọc Data cháy túi:** Firestore tính tiền dựa trên SỐ LẦN ĐỌC. Một màn hình Chat có 100 tin nhắn, bạn reload màn hình -> Mất 100 lần đọc. Một ngày user vào ra 100 lần -> 10,000 lần đọc. App có 10,000 users -> Firebase khóa tài khoản đòi nạp tiền. **Cách phòng tránh:** Dùng `limit(20)` để phân trang, không bao giờ load toàn bộ DB.
- **Rule thả cửa:** Cấu hình Security Rules là `allow read, write: if true;`. Ai có mã của app bạn cũng có thể nhảy vào xóa sạch database. **Cách phòng tránh:** LUÔN cấu hình rule `if request.auth != null` (chỉ user đã login mới được đọc ghi).

### 🚀 Mini Pet Project: Chat Room Toàn cầu (Global Chat)

**Yêu cầu:**
1. Tạo 1 project Firebase, chạy `flutterfire configure`. Bật dịch vụ Authentication (Anonymous) và Firestore Database trên Console Firebase.
2. Khi mở app, bấm nút "Đăng nhập Ẩn danh" (Anonymous) bằng mã `FirebaseAuth.instance.signInAnonymously()`.
3. Màn hình chính có một danh sách `StreamBuilder` trỏ vào collection tên là `global_chat`.
4. Dưới cùng có `TextField` và nút Gửi. Khi gõ chữ, đẩy Data vào `global_chat` với trường `text` và `createdAt` (Timestamp).
5. Code xong, build ra điện thoại và mở máy ảo. Chát thử trên điện thoại và nhìn máy ảo tự hiện chữ (Real-time). Phê!
