# Flutter 101.2 — hiểu ứng dụng đầu tiên và tạo nút bấm

Bạn đã chạy được `Hello, Flutter!`. Bài này giải thích từng mảnh code và biến màn hình tĩnh thành app có thể tương tác. Mục tiêu cuối bài: một màn hình hiển thị số lần bấm nút.

## Trước khi bắt đầu

Mở terminal tại app bạn đã tạo và chạy app:

```zsh
cd hello_flutter
flutter run -d chrome
```

Trong lúc lệnh này đang chạy, hãy lưu file sau mỗi lần sửa. Flutter sẽ cập nhật bằng hot reload; nếu không, quay lại Terminal và nhấn `r`.

## 1. Flutter được tạo từ widget

**Widget** là một thành phần mô tả giao diện. Chữ, nút, khoảng cách, một trang màn hình — tất cả đều là widget.

Hãy hình dung widget như các khối LEGO: ghép widget nhỏ vào widget lớn để thành một màn hình.

```text
MaterialApp             ứng dụng
└── Scaffold            một màn hình chuẩn
    ├── AppBar          thanh tiêu đề
    └── body
        └── Center      căn giữa nội dung
            └── Text    dòng chữ
```

## 2. Đọc code cơ bản

Thay nội dung `lib/main.dart` bằng đoạn này:

```dart
import 'package:flutter/material.dart';

void main() {
  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return const MaterialApp(
      debugShowCheckedModeBanner: false,
      home: Scaffold(
        appBar: AppBar(title: Text('Flutter 101')),
        body: Center(
          child: Text(
            'Xin chào Flutter!',
            style: TextStyle(fontSize: 28),
          ),
        ),
      ),
    );
  }
}
```

Giải thích từng phần:

| Code | Nó là gì? | Tác dụng |
| --- | --- | --- |
| `import 'package:flutter/material.dart';` | Lệnh nhập thư viện Material của Flutter. | Cho phép dùng widget như `Text`, `Center`, `Scaffold`, `AppBar`, `ElevatedButton`. |
| `void main()` | Điểm bắt đầu của chương trình Dart. | Flutter chạy hàm này trước tiên. |
| `runApp(...)` | Hàm khởi động Flutter. | Nhận widget gốc và hiển thị nó lên màn hình. |
| `MyApp` | Widget do ta tự đặt tên. | Là widget gốc của ứng dụng này. Tên class thường viết hoa. |
| `extends StatelessWidget` | Khai báo đây là widget **không có state thay đổi**. | Phù hợp với UI tĩnh, ví dụ chỉ hiển thị chữ/logo. |
| `build(...)` | Hàm mô tả UI của widget. | Flutter gọi lại nó khi cần vẽ giao diện. Nó phải trả về một widget. |
| `MaterialApp` | Widget bao ngoài ứng dụng theo phong cách Material Design. | Cung cấp theme, điều hướng và cấu hình chung. |
| `Scaffold` | Khung một màn hình Material. | Có các vùng quen thuộc như `appBar`, `body`, `floatingActionButton`. |
| `AppBar` | Thanh ở đầu trang. | Hiển thị tiêu đề hoặc các nút hành động. |
| `body` | Vùng nội dung chính của `Scaffold`. | Nơi ta đặt phần UI của trang. |
| `Center` | Widget bố cục. | Đặt widget con ở chính giữa vùng cha. |
| `Text` | Widget hiển thị văn bản. | Hiển thị `Xin chào Flutter!`; `style` dùng để đổi cỡ chữ. |

### `const` nghĩa là gì?

`const` nói rằng widget/dữ liệu này không thay đổi. Flutter có thể tối ưu khi dùng nó. Hãy thêm `const` khi VS Code gợi ý và giá trị bên trong là cố định. Đừng lo nếu chưa biết đặt ở đâu: Dart analyzer sẽ chỉ ra bằng biểu tượng bóng đèn.

## 3. Vì sao `StatelessWidget` chưa đủ?

App ở trên luôn hiển thị một câu giống nhau. Giả sử ta muốn bấm nút để số tăng từ 0 lên 1, 2, 3... Giá trị đó **thay đổi theo thao tác người dùng**, nên ta gọi nó là **state** (trạng thái).

- `StatelessWidget`: UI không tự thay đổi theo dữ liệu nội bộ.
- `StatefulWidget`: UI có dữ liệu nội bộ có thể thay đổi, ví dụ bộ đếm, ô nhập liệu, trạng thái loading.

Khi state thay đổi, ta gọi `setState`. Nó báo cho Flutter: “dữ liệu đã đổi, hãy chạy lại `build` để vẽ UI mới.”

## 4. Thực hành: app đếm số lần bấm

Thay toàn bộ `lib/main.dart` bằng code sau:

```dart
import 'package:flutter/material.dart';

void main() {
  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return const MaterialApp(
      debugShowCheckedModeBanner: false,
      home: CounterPage(),
    );
  }
}

class CounterPage extends StatefulWidget {
  const CounterPage({super.key});

  @override
  State<CounterPage> createState() => _CounterPageState();
}

class _CounterPageState extends State<CounterPage> {
  int count = 0;

  void increaseCount() {
    setState(() {
      count = count + 1;
    });
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Bộ đếm')),
      body: Center(
        child: Column(
          mainAxisAlignment: MainAxisAlignment.center,
          children: [
            const Text('Bạn đã bấm:'),
            Text(
              '$count lần',
              style: const TextStyle(fontSize: 32),
            ),
            const SizedBox(height: 16),
            ElevatedButton(
              onPressed: increaseCount,
              child: const Text('Tăng lên'),
            ),
          ],
        ),
      ),
    );
  }
}
```

### Luồng hoạt động khi bấm nút

```text
Bạn bấm "Tăng lên"
        ↓
ElevatedButton gọi increaseCount()
        ↓
setState tăng count lên 1
        ↓
Flutter gọi lại build()
        ↓
Text hiển thị giá trị count mới
```

### Các phần mới trong code

| Code | Nó là gì? | Tác dụng |
| --- | --- | --- |
| `StatefulWidget` | Loại widget có state. | Tạo phần UI cần thay đổi theo thời gian hoặc thao tác. |
| `State<CounterPage>` | Nơi giữ state của `CounterPage`. | Chứa biến `count`, các hàm thay đổi biến và hàm `build`. |
| `_CounterPageState` | Class state có dấu `_` ở đầu tên. | `_` nghĩa là class này chỉ dùng bên trong file hiện tại (private). |
| `int count = 0;` | Biến số nguyên ban đầu bằng 0. | Lưu số lần người dùng đã bấm. |
| `setState(() { ... })` | Hàm của Flutter State. | Cập nhật state và yêu cầu Flutter vẽ lại UI. Nếu bỏ nó, biến có thể đổi nhưng màn hình không cập nhật. |
| `Column` | Widget bố cục theo chiều dọc. | Xếp các widget con từ trên xuống dưới. |
| `children: [...]` | Danh sách widget con của `Column`. | Một `Column` có nhiều con, nên dùng danh sách. |
| `mainAxisAlignment: MainAxisAlignment.center` | Cấu hình căn chỉnh của `Column`. | Đưa cả nhóm nội dung vào giữa theo chiều dọc. |
| `SizedBox(height: 16)` | Widget tạo một khoảng trống cao 16 pixel. | Tách chữ khỏi nút để UI dễ nhìn hơn. |
| `ElevatedButton` | Nút Material. | Khi bấm, gọi hàm ở `onPressed`. |
| `onPressed: increaseCount` | Callback — hàm sẽ chạy khi người dùng bấm. | Kết nối nút với hành động tăng số. Không có `()` vì ta truyền hàm, chưa gọi hàm ngay. |
| `'$count lần'` | String interpolation của Dart. | Chèn giá trị biến `count` vào chuỗi chữ. |

## 5. Tự thử thay đổi nhỏ

Làm từng mục, lưu file và quan sát kết quả:

1. Đổi `count = count + 1` thành `count = count + 2`.
2. Đổi `fontSize: 32` thành `fontSize: 48`.
3. Đổi chữ trên nút thành `Bấm tôi`.
4. Đổi `Column` thành `Row`, rồi xem điều gì xảy ra. Sau đó đổi lại `Column`.
5. Thêm một nút thứ hai để reset về 0:

```dart
ElevatedButton(
  onPressed: () {
    setState(() {
      count = 0;
    });
  },
  child: const Text('Đặt lại'),
),
```

Đặt nút này vào danh sách `children`, sau `SizedBox` hoặc sau nút tăng. Đây là ví dụ về **anonymous function** (hàm không đặt tên): nó được viết ngay tại chỗ và chỉ dùng cho nút này.

## Ghi nhớ sau bài này

1. Flutter xây giao diện bằng các widget lồng nhau.
2. `build()` trả về giao diện hiện tại từ dữ liệu hiện tại.
3. UI tĩnh dùng `StatelessWidget`; UI cần thay đổi dùng `StatefulWidget`.
4. Khi đổi state, gọi `setState` để Flutter vẽ lại.

## Bài tiếp theo nên học

Hãy học bố cục: `Row`, `Column`, `Container`, `Padding`, `Expanded` và cách tránh lỗi tràn màn hình. Sau đó ta có thể làm một giao diện thẻ hồ sơ nhỏ thay vì chỉ dùng bộ đếm.
