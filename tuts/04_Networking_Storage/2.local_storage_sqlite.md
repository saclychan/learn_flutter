# 2. Local Storage & SQLite Deep Dive

Lưu trữ dữ liệu ngoại tuyến (offline) là tính năng tối quan trọng để app chạy mượt mà ngay cả khi mất mạng. Hôm nay chúng ta sẽ giải phẫu từ Shared Preferences tới SQLite.

## 🌟 1. Từ Newbie: Key-Value vs Relational Data

- **Shared Preferences**: Dùng để lưu mấy thứ lặt vặt như cấu hình (Theme dark/light, ngôn ngữ, boolean "hasSeenOnboarding"). Nhớ nhé, KHÔNG LƯU JSON TO TƯỚNG vào đây!
- **SQLite (`sqflite`)**: Khi bạn có hàng ngàn bản ghi, cần tìm kiếm, lọc (query) phức tạp (ví dụ: Lấy 10 hóa đơn gần nhất có giá trị > 500k).

## 🧠 2. Tới Senior: Database Migration & Threading

**Nỗi đau Migration:**
Hôm nay bạn tạo bảng `Users(id, name)`. Tháng sau sếp bảo thêm cột `avatar`. Nếu bạn chỉ sửa câu lệnh `CREATE TABLE`, app của người dùng cũ sẽ CRASH lập tức vì bảng `Users` cũ không có cột `avatar`.
**Giải pháp:** Phải tăng `version` của DB và viết logic trong `onUpgrade`.

**Vấn đề Threading (Isolates):**
SQLite ở Flutter chạy trên luồng chính (Main Thread/UI Thread) thông qua nền tảng Native. Nếu bạn query 100,000 dòng, UI của bạn sẽ bị "đứng hình". Senior sẽ chuyển các query siêu nặng sang **Isolate** (luồng chạy nền của Dart) để không block UI.

## 💡 Lời khuyên từ Google / Dart Style Guide

> **Avoid** executing heavy synchronous work on the main isolate.
Nếu parse JSON từ SQLite trả về quá lớn, hãy dùng `compute()` để parse ở background.

## 🤕 Nỗi đau Junior (Junior Pitfalls)

❌ **SAI (Không Migration & Chèn SQL Injection):**
```dart
// SQL Injection siêu nguy hiểm
db.rawQuery("SELECT * FROM Users WHERE name = '" + userInput + "'");
```

✅ **ĐÚNG (Dùng Parameterized Query & Migration rõ ràng):**
```dart
// An toàn 100%
db.query('Users', where: 'name = ?', whereArgs: [userInput]);

// Xử lý Migration
onUpgrade: (db, oldVersion, newVersion) {
  if (oldVersion < 2) {
    db.execute("ALTER TABLE Users ADD COLUMN avatar TEXT;");
  }
}
```

## 🐛 Thử Thách Gỡ Lỗi (Intentional Bugs)

Hãy tìm lỗi kết nối DB rỉ máu (Memory Leak) trong đoạn code này:

```dart
class UserRepository {
  Future<List<User>> getUsers() async {
    // Mở DB mỗi khi gọi hàm 👇
    Database db = await openDatabase('my_db.db');
    return await db.query('Users');
  }
}
```
**Đáp án:** Mở connection liên tục mà không đóng, hoặc mở lại nhiều lần gây tràn bộ nhớ và locked database.
**Cách fix:** Áp dụng Singleton Pattern cho Database connection. Chỉ mở `db` 1 lần duy nhất lúc khởi động app và dùng chung cho mọi truy vấn.
