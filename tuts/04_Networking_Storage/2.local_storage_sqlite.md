# Bài 3: Lưu trữ Dữ liệu Cục bộ (Local Storage & SQLite)

Để app hoạt động mượt mà ngay cả khi không có mạng (Offline First), bạn cần lưu dữ liệu cục bộ vào bộ nhớ máy điện thoại.

> 💡 **Fun Fact:** Flutter không tự sinh ra một cơ sở dữ liệu nào cả. Nó cung cấp các plugin để giao tiếp trực tiếp với hệ thống File hoặc SQLite gốc của iOS và Android.

## 1. SharedPreferences (Lưu rác, nhẹ)
Chuyên dùng để lưu các config đơn giản: Trạng thái login (Token), Dark/Light theme, Cài đặt âm thanh.
*Tuyệt đối KHÔNG dùng SharedPreferences để lưu chuỗi JSON dài hay một mảng danh sách hàng nghìn phần tử. Nó sẽ làm đứng app khi đọc/ghi.*

```dart
final prefs = await SharedPreferences.getInstance();
// Ghi dữ liệu
await prefs.setString('theme', 'dark');
// Đọc dữ liệu
final theme = prefs.getString('theme') ?? 'light';
```

## 2. Lưu File nội bộ (path_provider)
Khi bạn down cái ảnh hoặc file PDF về máy, bạn cần biết đường dẫn thư mục ẩn của app trên iOS/Android để cất file vào.
```dart
final directory = await getApplicationDocumentsDirectory();
final path = directory.path;
final file = File('$path/my_note.txt');
await file.writeAsString('Bí mật của tôi');
```

## 3. SQLite (Cơ sở dữ liệu Quan hệ)
Khi bạn có một bảng Hóa Đơn, một bảng Sản Phẩm, và bạn cần lưu hàng nghìn dòng, hãy dùng `sqflite`. Nó chính thống, dùng chung ngôn ngữ truy vấn SQL.

```dart
final db = await openDatabase(
  join(await getDatabasesPath(), 'shop_database.db'),
  onCreate: (db, version) {
    // Tạo bảng khi mở lần đầu
    return db.execute(
      'CREATE TABLE dogs(id INTEGER PRIMARY KEY, name TEXT, age INTEGER)',
    );
  },
  version: 1,
);

// Thêm dữ liệu cực dễ
await db.insert('dogs', {'id': 1, 'name': 'Corgi', 'age': 2});
```

> 🧠 **Senior Detail:** SQLite khá cứng nhắc vì phải viết chuỗi lệnh SQL thô. Trong thực tế, các Senior hay dùng các thư viện CSDL NoSQL hướng đối tượng (như `Hive` hay `Isar`) vì chúng lưu thẳng Object vào ổ cứng, tốc độ đọc ghi tính bằng Micro-giây và không cần viết câu lệnh CREATE TABLE!

## 🛑 Những nỗi đau và ngộ nhận khi còn Junior
- **Mơ mộng SharedPreferences là Database:** Junior đẩy cả mảng Object bọc thành JSON dài thò lò vào SharedPreferences. Hôm sau mở app bị lag cục bộ vì quá trình `getInstance()` của SharedPrefs bị nghẽn cổ chai RAM. **Cách phòng tránh:** Cái gì là Dữ liệu (Hàng hóa, User, Lịch sử) thì quăng vào SQLite/Hive. SharedPrefs chỉ dành cho Config (Cấu hình)!
- **Đọc ghi Database trên UI:** Nhét hàm `db.insert()` vào trong `build` hoặc đợi kết quả Future ngay trong widget. **Cách phòng tránh:** Database cũng là một API cục bộ! Hãy tạo một lớp Repository để bọc nó lại.

### 🚀 Mini Pet Project: App Ghi chú Offline (Offline Note App)

**Yêu cầu:**
1. Cài đặt thư viện `sqflite` và `path_provider`.
2. Viết một class `DatabaseHelper` có một instance duy nhất (Singleton). Trong đó viết hàm khởi tạo Database bảng `notes (id, title, content)`.
3. Viết 2 hàm: `insertNote()` và `getNotes()`.
4. Tạo UI đơn giản: Một ô nhập Text và nút Save, một `ListView` hiển thị kết quả từ `getNotes()`.
5. Tắt mạng, gõ ghi chú, bấm Save, tắt nóng App đi mở lại. Ghi chú vẫn còn nguyên ở đó.
