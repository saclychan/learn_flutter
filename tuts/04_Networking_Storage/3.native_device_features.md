# Bài 4: Giao tiếp với Phần cứng thiết bị (Native Device Features)

Flutter là UI Framework, nó không tự mình biết cách bật camera hay bật đèn pin. Nó dùng một cơ chế gọi là **Platform Channels** để gửi tin nhắn xuống hệ điều hành gốc (Swift/Kotlin) nhờ làm hộ. Các thư viện (Packages) trên pub.dev chính là cầu nối này.

> 💡 **Fun Fact:** Nếu bạn tìm được một cái thư viện Camera trên pub.dev mà bị lỗi trên iOS, bạn hoàn toàn có thể tự mở thư mục `ios` của Flutter project ra, viết code Swift native gọi Camera, rồi dùng Platform Channel tự truyền dữ liệu lên Dart. Đỉnh cao chưa!

## 1. Dùng Camera chụp ảnh (image_picker)
Gần như 100% app đều có tính năng đổi Avatar. `image_picker` là thư viện quốc dân.

```dart
final ImagePicker picker = ImagePicker();
// Bật giao diện Camera chụp ảnh
final XFile? photo = await picker.pickImage(source: ImageSource.camera);

if (photo != null) {
  // Lấy đường dẫn file ảnh vừa chụp
  File imageFile = File(photo.path);
  // Hiển thị ra UI: Image.file(imageFile)
}
```
**Lưu ý cực kỳ quan trọng:** Ở iOS, để bật được Camera, bạn BẮT BUỘC phải mở file `ios/Runner/Info.plist` và khai báo khóa quyền `NSCameraUsageDescription`, nếu không App sẽ bị crash lập tức.

## 2. Lấy vị trí GPS (location)
Để biết User đang đứng đâu để giao hàng:

```dart
Location location = Location();
// Xin quyền truy cập GPS
PermissionStatus permissionGranted = await location.requestPermission();
if (permissionGranted == PermissionStatus.granted) {
  // Bắn GPS lấy tọa độ!
  LocationData locationData = await location.getLocation();
  print("Tôi đang ở: \${locationData.latitude}, \${locationData.longitude}");
}
```

## 3. Nhúng Google Maps
Chỉ cần cài gói `google_maps_flutter`, bạn có thể nhúng hẳn cái bản đồ vào trong App, gắn Marker (ghim) vào tọa độ vừa lấy được.

> 🧠 **Senior Detail:** Google Maps dùng Platform Views (Tức là nó khoét một lỗ hổng trên lớp UI của Flutter để lôi thẳng View gốc của Android/iOS lên hiển thị). Nó rất nặng! Chỉ load bản đồ khi thật sự cần thiết. Nếu chỉ cần hiển thị cái ảnh tĩnh của khu vực, hãy dùng Google Maps Static API (gọi API HTTP trả về file `.jpg`) sẽ nhẹ hơn gấp 10 lần!

## 🛑 Những nỗi đau và ngộ nhận khi còn Junior
- **Quên xin quyền hệ thống:** Nhắm mắt gọi API Camera/Location. App crash văng thẳng cổ ra ngoài. Hì hục đi tìm bug Flutter. **Cách phòng tránh:** LUÔN nhớ kiểm tra `Permission` (quyền) thông qua gói `permission_handler` trước khi gọi bất cứ tính năng phần cứng nào. Và đừng quên sửa cấu hình `AndroidManifest.xml` (Android) và `Info.plist` (iOS).
- **Chụp ảnh 10MB ném lên mạng:** Gọi Camera xong lấy file gốc ném thẳng lên Server làm hỏng băng thông. **Cách phòng tránh:** `image_picker` có thuộc tính `imageQuality: 50`. Hãy nén ảnh lại trước khi dùng!

### 🚀 Mini Pet Project: Màn hình Check-in Vị Trí (Check-in Snap)

**Yêu cầu:**
1. Cài đặt gói `image_picker` và `location`. Nhớ cấu hình quyền trong `Info.plist` (iOS) / `AndroidManifest` (Android) nhen.
2. Tạo màn hình có 1 cái Avatar bự (chưa có ảnh thì để màu xám). Bên dưới có cái nút "Chụp hình Check-in".
3. Khi bấm nút: 
   - Xin quyền và gọi Camera để chụp 1 tấm hình.
   - Khi có hình rồi, xin quyền GPS và lấy tọa độ.
4. Hiển thị tấm hình lên cái Avatar bự lúc nãy, và hiện tọa độ (Lat/Lng) dưới dạng text phía dưới tấm ảnh.
