# 3. Native Features: Camera, GPS & Quyền Truy Cập

Giao diện đẹp là chưa đủ, app xịn phải biết giao tiếp với phần cứng máy: chụp ảnh, lấy tọa độ, v.v.

## 🌟 1. Từ Newbie: Plugins là cầu nối

Flutter viết bằng Dart, phần cứng chạy bằng Java/Kotlin/Swift. Làm sao chúng nói chuyện?
Thông qua **Method Channel**. Các plugin (như `camera`, `geolocator`) đã làm sẵn việc này. Bạn chỉ cần gọi code Dart, plugin sẽ lo việc "bắn" thông điệp sang Native.

## 🧠 2. Tới Senior: Vòng Đời Quyền (Permissions) & Xử Lý Nền

**Nỗi đau Permission:**
Apple và Google dạo này cực gắt vụ quyền riêng tư.
Bạn không thể cứ gọi hàm lấy tọa độ là xong. Bạn phải:
1. Hỏi quyền.
2. Xử lý trường hợp người dùng từ chối (Denied).
3. Xử lý trường hợp từ chối vĩnh viễn (Permanently Denied) -> Phải mở Settings máy.

**Vấn đề Background (Chạy nền):**
Junior gọi GPS ngon lành lúc mở app. Tắt màn hình đi? App chết ngỏm, không tracking được nữa.
Senior biết cách dùng Foreground Services (Android) hoặc Background Fetch để giữ app sống sót.

## 💡 Lời khuyên từ Google / Dart Style Guide

> **Do** provide rationale before requesting permissions.
Trước khi bật popup xin quyền Camera, hãy hiện một thông báo giải thích: "Chúng tôi cần Camera để bạn có thể chụp ảnh Profile". Tỉ lệ người dùng cho phép sẽ cao hơn 80%!

## 🤕 Nỗi đau Junior (Junior Pitfalls)

❌ **SAI (Gọi chức năng mà không check quyền trước):**
```dart
void getLocation() async {
  // Bùm! Crash app nếu chưa xin quyền
  Position position = await Geolocator.getCurrentPosition(); 
  print(position);
}
```

✅ **ĐÚNG (Check kỹ càng 3 vòng):**
```dart
void getLocation() async {
  LocationPermission permission = await Geolocator.checkPermission();
  if (permission == LocationPermission.denied) {
    permission = await Geolocator.requestPermission();
    if (permission == LocationPermission.denied) {
      showError("Bạn đã từ chối quyền");
      return;
    }
  }
  if (permission == LocationPermission.deniedForever) {
    Geolocator.openAppSettings(); // Mở setting
    return;
  }
  // Tới đây mới an toàn 100%
  Position position = await Geolocator.getCurrentPosition();
}
```

## 🐛 Thử Thách Gỡ Lỗi (Intentional Bugs)

Đoạn code chụp ảnh này chạy rò rỉ bộ nhớ (memory leak). Tại sao?

```dart
class CameraScreen extends StatefulWidget {
  @override
  _CameraScreenState createState() => _CameraScreenState();
}
class _CameraScreenState extends State<CameraScreen> {
  CameraController? controller;

  @override
  void initState() {
    super.initState();
    controller = CameraController(cameras[0], ResolutionPreset.max);
    controller!.initialize().then((_) {
      if (!mounted) return;
      setState(() {});
    });
  }
  // Lỗi ở đây: Quên hàm dispose() 👇
  
  @override
  Widget build(BuildContext context) {
    return CameraPreview(controller!);
  }
}
```
**Đáp án:** `CameraController` tiêu tốn cực nhiều RAM và giữ chặt Camera phần cứng. Nếu bạn không gọi `controller.dispose()` trong `dispose()` của Widget, khi thoát màn hình, Camera vẫn bị app ngậm lấy, máy nóng rực và các app khác không mở Camera được!
