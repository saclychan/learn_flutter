# Bài 4: Kết Nối Thời Gian Thực (WebSockets & GraphQL)

Học gọi API bằng HTTP (REST) là bắt buộc, nhưng HTTP có một giới hạn chết người: Client phải HỎI thì Server mới TRẢ LỜI. Nếu làm app Chat hay chứng khoán, bạn không thể cứ mỗi 1 giây lại cho app gọi HTTP một lần (Server sẽ bốc khói).

Giải pháp cho độ trễ 0.001s chính là WebSockets! Còn giải pháp cho việc truy vấn dữ liệu linh hoạt (Lấy đúng cái mình cần) chính là GraphQL.

> 💡 **Fun Fact:** Giao thức WebSocket (`ws://`) giữ một đường hầm (tunnel) MỞ LIÊN TỤC giữa Client và Server. Chỉ cần một bên ném data vào, bên kia sẽ nhận được ngay tức khắc mà không cần khởi tạo lại kết nối HTTP (Bắt tay 3 bước).

## 1. WebSockets (Giao tiếp thời gian thực)
Flutter hỗ trợ WebSockets tận răng với package `web_socket_channel`.

```dart
// 1. Kết nối tới Server (Dùng wss:// cho bảo mật)
final channel = WebSocketChannel.connect(
  Uri.parse('wss://echo.websocket.events'),
);

// 2. Gửi tin nhắn lên Server (Push)
channel.sink.add('Xin chào Server, tôi là Flutter!');

// 3. Lắng nghe Server trả lời liên tục (Stream)
StreamBuilder(
  stream: channel.stream,
  builder: (context, snapshot) {
    if (snapshot.hasData) return Text('\${snapshot.data}');
    return CircularProgressIndicator();
  },
)

// 4. Khi rời màn hình, nhớ đóng cửa (RẤT QUAN TRỌNG)
@override
void dispose() {
  channel.sink.close();
  super.dispose();
}
```

## 2. GraphQL (Truy vấn dữ liệu tương lai)
REST API cứng nhắc. API `/user/1` luôn trả về 50 trường dữ liệu dù bạn chỉ cần cái Tên.
GraphQL cho phép Client ĐẶT HÀNG đúng những gì mình muốn. Bạn dùng thư viện `graphql_flutter`.

```graphql
# Client xin đúng 2 thông tin: id và name
query {
  user(id: 1) {
    id
    name
  }
}
```

> 🧠 **Senior Detail:** GraphQL có 3 khái niệm: **Query** (Giống HTTP GET), **Mutation** (Giống POST/PUT để sửa data), và **Subscription** (Dùng WebSockets ngầm để nhận data realtime). Nếu công ty xài GraphQL, gói `graphql_flutter` có sẵn một cái Widget tên là `Subscription` giúp bạn render data thời gian thực mà không cần viết StreamBuilder luôn!

## 🛑 Những nỗi đau và ngộ nhận khi còn Junior
- **Mở WebSocket rồi bỏ quên:** Junior mở luồng Socket nhưng lúc User bấm Back thoát màn hình lại quên gọi `sink.close()`. Lát sau User quay lại màn hình đó, app mở LUỒNG SỐ 2. Ra vô 10 lần là 10 luồng Socket mở song song, hút sạch pin điện thoại. **Cách phòng tránh:** LUÔN đóng Socket ở hàm `dispose()`.
- **Dùng REST giả lập Real-time (Long Polling):** Dùng `Timer.periodic` gọi API mỗi 3 giây để lấy tin nhắn mới. **Cách phòng tránh:** Bỏ ngay tư duy đó. Nếu dính tới Chat, Trực tiếp (Live), Chứng khoán, Tọa độ xe ôm -> Phải dùng WebSockets, MQTT, hoặc Firebase Realtime Database.

### 🚀 Mini Pet Project: App Định Giá Bitcoin (Crypto Ticker)

**Yêu cầu:**
1. Cài đặt package `web_socket_channel`.
2. Binance cung cấp một WebSocket API công khai (Không cần đăng nhập): `wss://stream.binance.com:9443/ws/btcusdt@trade`.
3. Trong hàm `initState`, mở kết nối tới địa chỉ trên.
4. Màn hình giữa dùng `StreamBuilder` hứng luồng `channel.stream`. Dữ liệu đổ về là chuỗi JSON. Dùng `jsonDecode` lấy trường `"p"` (Giá hiện tại).
5. In ra màn hình cái giá Bitcoin đang giật giật lên xuống từng giây một! Đừng quên đóng `channel` trong `dispose`.
